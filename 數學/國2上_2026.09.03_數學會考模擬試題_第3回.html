第 1 題 — 正負數乘法判斷疑難題
已知 a=(−12)×(−34)×(−56)×(−78)，b=(−123)×(−345)×(−678)，判斷下列敘述何者正確？
a、b皆為正數a、b皆為負數a為負數，b為正數a為正數，b為負數
解題 ▶
🔑 核心觀念
連乘積的正負號，由「負數因數的個數」決定：偶數個負數相乘 → 正數；奇數個負數相乘 → 負數。
💭 思考邏輯
不用真的算出 a、b 的數值，只要數兩邊各有幾個負數相乘即可。
📑 解題步驟
①a 有 4 個負數相乘（偶數個）→ a 為正數
②b 有 3 個負數相乘（奇數個）→ b 為負數
答案：(D) a為正數，b為負數
第 2 題 — 分數四則運算疑難題
算式 3.5÷[(1/4−1)×(3+1/2)] 之值為何？
−4/3−147/3−49/311
解題 ▶
🔑 核心觀念
四則運算要先算中括號內的部分，再處理除法；分數與小數混合時，先統一成分數比較不會出錯。
💭 思考邏輯
先算 (1/4−1) 跟 (3+1/2)，兩者相乘後，再用 3.5 去除以這個乘積。
📑 解題步驟
①1/4−1 = −3/4
②3+1/2 = 7/2
③(−3/4)×(7/2) = −21/8
④3.5÷(−21/8) = 3.5×(−8/21) = −4/3
答案：(A) −4/3
第 3 題 — 指數與因數判斷
若 A 為一數，且 A=2⁶×5⁵×13⁴，則下列選項中所表示的數，何者是 A 的因數？
2⁴×75⁶×13³2⁴×5⁴×13⁴2⁶×5⁶×13⁶
解題 ▶
🔑 核心觀念
B 是 A 的因數，代表 B 的每個質因數指數都要「小於等於」A 對應質因數的指數，而且不能出現 A 沒有的質因數。
💭 思考邏輯
逐一檢查四個選項裡各質因數的指數，有沒有超過 A 裡對應的上限（2的上限6、5的上限5、13的上限4）。
📑 解題步驟
①(A) 含有質因數 7，A 裡沒有 7，不是因數
②(B) 5⁶ 超過 A 的 5⁵ 上限，不是因數
③(C) 2⁴≤2⁶、5⁴≤5⁵、13⁴≤13⁴，全部符合，是因數
④(D) 5⁶、13⁶ 都超過上限，不是因數
答案：(C) 2⁴×5⁴×13⁴
第 4 題 — 指數律計算疑難題
算式 4³×5⁶ 之值為何？
2036080001000000
解題 ▶
🔑 核心觀念
當底數不同但指數可以湊成一樣時，可以先把底數相乘再一起取指數：aⁿ×bⁿ=(a×b)ⁿ。
💭 思考邏輯
4³ 可以改寫成 (2²)³=2⁶，這樣就跟 5⁶ 有相同指數 6，能合併成 (2×5)⁶。
📑 解題步驟
①4³ = (2²)³ = 2⁶
②2⁶×5⁶ = (2×5)⁶ = 10⁶
③10⁶ = 1000000
答案：(D) 1000000
第 5 題 — 數線上的等距點疑難題
數線上有 O、A、B、C 四點，各點位置與各點所表示的數如圖所示（A=−9，C=c，O=0，B=9，順序為 A、C、O、B）。若數線上有一點 D，D 點所表示的數為 d，且 |d−(−9)|=|d−c|，則關於 D 點的位置，下列敘述何者正確？
介於A、C之間介於C、O之間介於O、B之間在C的右邊
解題 ▶
🔑 核心觀念
|d−(−9)|=|d−c| 代表 D 到 A(−9) 的距離，等於 D 到 C(c) 的距離，也就是說 D 是 A、C 兩點的「正中間」（中點）。
💭 思考邏輯
只要知道 D 是 A 與 C 的中點，不需要知道 c 的精確數值，中點必定落在 A、C 兩點之間。
📑 解題步驟
①|d−(−9)|=|d−c| → D 到 A 的距離 = D 到 C 的距離
②滿足這個條件的點，就是線段 AC 的中點
③中點必落在 A、C 之間
答案：(A) 介於A、C之間
第 6 題 — 科學記號大小判斷
已知 p=9.36×10⁻⁵，下列關於 p 值的敘述何者正確？
小於0介於0與1兩數之間，兩數中比較接近0介於0與1兩數之間，兩數中比較接近1大於1
解題 ▶
🔑 核心觀念
10⁻⁵ 是一個非常小的正數（0.00001），乘上 9.36 之後仍然遠小於 1。
💭 思考邏輯
把科學記號展開成一般小數，直接跟 0、1 比大小就知道位置。
📑 解題步驟
①p = 9.36×10⁻⁵ = 0.0000936
②0.0000936 介於 0 與 1 之間，且非常接近 0
答案：(B) 介於0與1兩數之間，兩數中比較接近0
第 7 題 — 指數律倍數關係疑難題
25³ 是 5³ 的多少倍？
52550125
解題 ▶
🔑 核心觀念
25 可以寫成 5²，所以 25³ 可以整理成 5 的次方，再跟 5³ 比較就能看出倍數關係。
💭 思考邏輯
把 25³ 改寫成 (5²)³=5⁶，5⁶÷5³=5³，直接算出倍數。
📑 解題步驟
①25³ = (5²)³ = 5⁶
②5⁶ ÷ 5³ = 5³ = 125
答案：(D) 125
第 8 題 — 一次函數代入驗證
坐標平面上，方程式 y=−4x−5 的圖形通過下列哪一個點？
(−2,1)(−2,3)(−2,−1)(−2,−3)
解題 ▶
🔑 核心觀念
判斷一個點是否在方程式圖形上，只要把該點的 x 值代入方程式，看算出來的 y 是否等於該點的 y。
💭 思考邏輯
四個選項的 x 都是 −2，只要代入一次 x=−2 算出對應的 y，再對照哪個選項符合。
📑 解題步驟
①x=−2 時，y=−4×(−2)−5 = 8−5 = 3
②對照選項，(−2,3) 符合
答案：(B) (−2,3)
第 9 題 — 促銷微波爐總銷售額
右圖為頂好家電行的促銷活動傳單，已知促銷第一天美食牌微波爐賣出 10 台，且其銷售額為 41900 元。若活動期間此款微波爐總共賣出 50 台，則其總銷售額為多少元？
傳單內容：美食牌微波爐，原價 7800 元特價中，限量 50 台！前 20 台每台再折 800 元。
209500225500233500249500
解題 ▶
🔑 核心觀念
促銷分兩種價格：前 20 台在特價基礎上「再折 800 元」，第 21~50 台維持特價（沒有再折）。
💭 思考邏輯
第一天賣的 10 台一定都落在「前 20 台」的範圍內，所以可以用第一天的銷售額反推出特價，再分別算前20台跟後30台的總額。
📑 解題步驟
①設特價為 P，前20台每台 = P−800
②第一天10台都屬於前20台：10×(P−800)=41900 → P−800=4190 → P=4990
③前20台總額 = 20×4190 = 83800
④後30台總額 = 30×4990 = 149700
⑤總銷售額 = 83800+149700 = 233500
答案：(C) 233500
第 10 題 — 一元一次不等式疑難題
若滿足不等式 25<6−2(3+2x) 的最大整數解為 a，則 a 之值為何？
−6−7−8−9
解題 ▶
🔑 核心觀念
解不等式時，先展開化簡成 x 的範圍，再找符合條件的最大整數。
💭 思考邏輯
先把右邊展開整理成「x<某數」的形式，再判斷這個範圍裡最大的整數是多少。
📑 解題步驟
①6−2(3+2x) = 6−6−4x = −4x
②25<−4x → x<−25/4 = −6.25
③小於−6.25的最大整數是 −7
答案：(B) −7

第 12 題 — 指數律綜合運算疑難題
算式 (3⁴×5⁵)²×(3²×5³) 之值可用下列哪一個選項表示？
3⁸×5¹⁰3¹⁰×5¹³3⁶×5¹³3¹⁸×5²⁸
解題 ▶
🔑 核心觀念
(aᵐ)ⁿ=aᵐⁿ；同底數相乘指數相加：aᵐ×aⁿ=aᵐ⁺ⁿ。分別對 3 和 5 兩個底數處理。
💭 思考邏輯
先把括號的平方展開，再把兩個括號相乘的部分，依底數分別合併指數。
📑 解題步驟
①(3⁴×5⁵)² = 3⁸×5¹⁰
②3⁸×5¹⁰ × 3²×5³ = 3⁸⁺²×5¹⁰⁺³ = 3¹⁰×5¹³
答案：(B) 3¹⁰×5¹³

已知坐標平面上，一次函數 y=4x+2a 的圖形通過點 (1,−4)，其中 a 為一數，求 a 的值為何？
−884−4

第 14 題 — 二元一次聯立方程式
若二元一次聯立方程式 {2x+y=9, 3x−2y=10} 的解為 {x=a, y=b}，則 a+b 之值為何？
53113/2
解題 ▶
🔑 核心觀念
聯立方程式常用代入法或消去法求解，這裡用代入法比較快，因為第一式很容易解出 y。
💭 思考邏輯
先從第一式解出 y 用 x 表示，代入第二式求出 x，再回頭求 y，最後相加。
📑 解題步驟
①由 2x+y=9 得 y=9−2x
②代入 3x−2y=10：3x−2(9−2x)=10 → 3x−18+4x=10 → 7x=28 → x=4
③y=9−2(4)=1
④a+b = x+y = 4+1 = 5
答案：(A) 5
第 15 題 — 肉粽價格問題
如下圖，是艾琳與肉粽店老闆的對話情形。若每粒肉粽折扣前的價錢均相同，則根據圖中的內容，判斷每粒肉粽折扣前的價錢為多少元？
原始題目圖（三格對話）
28293031
解題 ▶
🔑 核心觀念
「一串8粒」，所以買2串=16粒、買3串=24粒。買3串時每一粒都少收1元（打折），要先算折扣後的總價再比較。
💭 思考邏輯
設每粒原價為 p 元。買2串是原價（16p），買3串是打折後的價錢（每粒 p−1 元，共24粒）。用「3串比2串貴224元」列式。
📑 解題步驟
①2串總價（原價）= 16p
②3串總價（折扣後）= 24×(p−1)
③24(p−1) − 16p = 224
④24p−24−16p=224 → 8p=248 → p=31
答案：(D) 31
第 16 題 — 二元一次方程式的解

「(x,y)是方程式的解」代表把這組數字代入方程式，左右兩邊會相等。
💭 思考邏輯
把 x=−2、y=3 分別代入四個選項，看哪一個成立。

①(A) −2+6=4≠−1
②(B) −2−6=−8≠1

第 17 題 — 點到鉛垂線的距離疑難題
已知坐標平面上有一直線 L 與一點 A。若 L 的方程式為 x=−3，A 點坐標為 (7,4)，則 A 點到直線 L 的距離為何？
10743
解題 ▶

第 18 題 — 平均數反推疑難題
某高中的籃球隊成員中，一、二年級的成員共有9人，三年級的成員有4人。一、二年級的成員身高(公分)如下：171、172、174、174、175、175、176、178、178。若隊中所有成員的平均身高為177公分，則隊中三年級成員的平均身高為幾公分？
177178180182
解題 ▶
🔑 核心觀念
平均數 = 總和 ÷ 人數。已知全隊平均，可以先反推全隊總身高，再扣掉已知的一二年級總和，求出三年級的總和跟平均。
💭 思考邏輯
分兩步：先加總一二年級9人的身高，再用「全隊平均×全隊人數」算出全隊總身高，兩者相減就是三年級的總身高。
📑 解題步驟
①一二年級9人身高總和 = 171+172+174+174+175+175+176+178+178 = 1573
②全隊13人總身高 = 177×13 = 2301
③三年級4人總身高 = 2301−1573 = 728
④三年級平均身高 = 728÷4 = 182
答案：(D) 182
第 19 題 — 座位售出比例合併疑難題
某場戲劇表演會販售的座位分成一樓與二樓兩個區域。若一樓售出與未售出的座位數比為5:4，二樓售出與未售出的座位數比為4:3，且此場戲劇表演會一、二樓未售出的座位數相等，則此場戲劇表演會售出與未售出的座位數比為何？
5:39:731:2440:31
解題 ▶
🔑 核心觀念
跟「豆漿米漿」類型的題目一樣：兩個比例的份量不同，要靠「未售出數量相等」這個條件，把兩組比例接成同一個變數。
💭 思考邏輯
分別設一樓、二樓的份數變數，用未售出相等建立關係，再算總售出、總未售出。
📑 解題步驟
①設一樓：售出=5k，未售出=4k
②設二樓：售出=4m，未售出=3m
③未售出相等：4k=3m → m=4k/3
④二樓售出 = 4m = 16k/3
⑤總售出 = 5k+16k/3 = 31k/3；總未售出 = 4k+3m = 4k+4k = 8k
⑥售出:未售出 = 31k/3 : 8k = 31:24
答案：(C) 31:24
第 20 題 — 停車費用計算疑難題
尚賀停車場為24小時營業，其收費方式如下表。已知阿南某日9:00進場停車，停了x小時後離場，x為整數。若阿南離場的時間介於當日的21:00~23:00間，則他此次停車的費用為多少元？
停車時段收費方式
08:00~20:0030元/小時，該時段最多收180元
20:00~08:0010元/小時，該時段最多收60元
若進場與離場時間不在同一時段，則兩時段分別計費
10x+6010x+7010x+18010x+240
解題 ▶
🔑 核心觀念
進場9:00在「日間時段」，離場21:00~23:00在「夜間時段」，兩個時段要分開計費，各自套用各自的每小時費率跟上限。
💭 思考邏輯
先算日間時段（9:00~20:00）停了幾小時、費用是多少（可能已經超過上限被封頂）；再算夜間時段（20:00~離場）停了 x−11 小時的費用。
📑 解題步驟
①日間時段：9:00~20:00 共11小時，費用=11×30=330元，超過上限180元 → 只收180元
②夜間時段：20:00~離場，共 (x−11) 小時，費用=10×(x−11)
③離場在21:00~23:00間，x−11 為1~3小時，10×(x−11)最多30元，未超過60元上限
④總費用 = 180+10(x−11) = 180+10x−110 = 10x+70
答案：(B) 10x+70
第 21 題 — 三根木棍重疊問題疑難題
下圖為甲、乙、丙三根筆直的木棍平行擺放在地面上的情形。已知乙有一部分只與甲重疊，其餘部分只與丙重疊，甲沒有與乙重疊的部分的長度為2公尺，丙沒有與乙重疊的部分的長度為5公尺。若乙的長度最長且甲、乙的長度相差x公尺，乙、丙的長度相差y公尺，則乙的長度為多少公尺？
原始題目圖
x+y+7x+y+3x+y−3x+y−7
解題 ▶
🔑 核心觀念
乙整根都被「用掉」了：一部分跟甲重疊、剩下的跟丙重疊，乙自己沒有獨立的部分。而甲、丙則各自有一段是獨立（不重疊）的。
💭 思考邏輯
把甲、丙的長度都用「獨立部分＋重疊部分」表示，再用「乙比甲長x」「乙比丙長y」列出方程式，求出重疊部分，最後相加得到乙的長度。
📑 解題步驟
①設 甲乙重疊=p，乙丙重疊=q，則 乙=p+q，甲=2+p，丙=q+5
②乙−甲=x：(p+q)−(2+p)=x → q−2=x → q=x+2
③乙−丙=y：(p+q)−(q+5)=y → p−5=y → p=y+5
④乙 = p+q = (y+5)+(x+2) = x+y+7
答案：(A) x+y+7

第 23 題 — 長方形旋轉求坐標疑難題
已知坐標平面上有一長方形ABCD，其坐標分別為A(0,0)、B(5,0)、C(5,2)、D(0,2)。今固定B點並將此長方形依順時針方向旋轉，如右圖所示。若旋轉後C點的坐標為(7,0)，則旋轉後D點的坐標為何？
原始題目圖
(7,5)(5,5)(7,7)(7,2)
解題 ▶
🔑 核心觀念
整個長方形繞 B 點旋轉，每個頂點與 B 的相對位置向量，會照同一個角度旋轉。先用 C 點旋轉前後的向量變化，找出旋轉角度的規律，再套用到 D 點。
💭 思考邏輯
把 B→C 的向量看成旋轉前，B→C'（新位置）看成旋轉後，觀察向量怎麼變化；同樣的變化規律套用在 B→D 上。
📑 解題步驟
①旋轉前 B→C 向量 = C−B = (5,2)−(5,0) = (0,2)
②旋轉後 B→C' 向量 = (7,0)−(5,0) = (2,0)
③(0,2)變成(2,0)，這是「順時針轉90°」的規律：(x,y)→(y,−x)
④B→D 向量 = D−B = (0,2)−(5,0) = (−5,2)
⑤套用同樣規律：(−5,2)→(2,5)
⑥D' = B+(2,5) = (5+2, 0+5) = (7,5)
答案：(A) (7,5)
第 24 題 — 熱傷害風險等級判斷疑難題
請閱讀下列敘述後，回答24~25題：為了降低中暑的機會，近年來部分國家會使用綜合溫度熱指數WBGT(℃)作為判斷熱傷害風險的指標。在戶外有日曬時，WBGT=0.7Tw+0.2Tg+0.1Td；在戶外無日曬或室內時，WBGT=0.7Tw+0.3Tg（Tw:自然濕球溫度、Tg:黑球溫度、Td:乾球溫度）。依WBGT數值可分五級：<21安全、21~25注意、25~28警戒、28~31高度警戒、≥31危險（每級為以上含~未滿）。
右表為戶外有日曬的甲地與室內的乙地在中午時所測量到的各種溫度。根據上文，甲地、乙地在中午時的熱傷害風險等級分別為何？

Tw27℃20℃
Tg32℃25℃
Td29℃25℃
注意、安全高度警戒、注意警戒、安全警戒、注意

第 25 題 — WBGT等級反推溫差疑難題
已知某室內運動場昨日中午的WBGT為23℃，今日中午的WBGT為「警戒」等級。根據上文，若此運動場這兩日中午的Tg相同，則該運動場今日中午的Tw比昨日中午的Tw，至少多了多少℃？（將結果以無條件進入法取概數至小數點後第一位）
2.12.94.25.8

室內用公式 WBGT=0.7Tw+0.3Tg。「至少多了多少」代表今日WBGT要取警戒等級的最小邊界值（25℃），因為Tg兩天相同，會在相減時直接消掉。
💭 思考邏輯
分別列出昨天、今天的WBGT算式，兩式相減時Tg會抵消，直接算出Tw的差。
📑 解題步驟
①警戒等級為25~28（含25），取最小邊界 今日WBGT=25

第 非選1 題 — 宣紙練習張數與星期推算疑難題
大勇買了一包宣紙練習書法，每星期一寫1張，星期二寫2張，星期三寫3張，星期四寫4張，星期五寫5張，星期六寫6張，星期日寫7張。若大勇從某年的7月1日開始練習，到7月31日練習完後累積寫完的宣紙總數已超過125張，則7月31日可能為星期幾？請求出所有可能的答案並完整說明理由。
解題 ▶
🔑 核心觀念
一整個星期（週一到週日）寫的張數固定是 1+2+3+4+5+6+7=28 張，跟從哪天開始無關。31天=4個完整星期(28天)+3天，這剩下的3天寫幾張，才是決定總數多寡的關鍵，而這3天正好是「從7月1日那個星期幾開始」算的前3天。
💭 思考邏輯
先固定「4個整星期＝112張」，只要專心算最後3天（即從7月1日的星期幾開始，連續3天）的張數總和有沒有讓總數超過125（也就是這3天要超過13張），再一一測試7月1日是星期幾。
📑 解題步驟
①31天 = 4整週(28天，張數固定112張) + 3天
②總數>125 → 4整週後多出的3天張數合計要 >125−112=13張
③逐一測試7月1日是星期幾，算「7月1日、2日、3日」這3天的張數和：
週一開始(1,2,3)=6；週二(2,3,4)=9；週三(3,4,5)=12；週四(4,5,6)=15；週五(5,6,7)=18；週六(6,7,1)=14；週日(7,1,2)=10
④只有週四(15)、週五(18)、週六(14)這三種開始方式，3天總和>13，符合條件
⑤7月31日 = 7月1日往後推30天 = 同一星期幾往後數2天（30÷7餘2）
⑥7月1日=週四 → 7月31日=週六；7月1日=週五 → 7月31日=週日；7月1日=週六 → 7月31日=週一
提醒：「請求出所有可能的答案」提醒這是多解題，一定要把三種情況都列出來、缺一個都算不完整。
答案：7月31日可能是星期六、星期日、或星期一
第 非選2 題 — 縮時攝影反比關係疑難題
縮時攝影是一種攝影技術，靠著調整「每幾秒拍攝一張照片」以及「製作影片時以每秒播放幾張照片的速度」這兩個變數，使得長度為數分鐘的影片能呈現出數小時、數天，甚至數年的景象變化。例如：對一個變動中的景象以每3秒拍攝一張照片的方式連續拍攝15小時，共會得到18000張照片，將這些照片以每秒播放30張的速度製作影片，可產生600秒的縮時影片。有一個影片比賽，規定參賽影片的長度須為15分鐘。小志打算利用縮時攝影將某風景區的景象變化製作成縮時影片參賽。請根據上述資訊回答下列問題，完整寫出你的解題過程並詳細解釋： (1) 若小志連續拍攝該風景區20小時的景象變化，並製作成15分鐘的縮時影片，則影片中的1秒呈現出拍攝當時幾秒的景象變化？ (2) 由於小志想將20小時的景象變化製作成15分鐘的縮時影片，所以當他將相機設定為每x秒拍攝一張照片時，便須以每秒播放y張的速度製作影片。請判斷x與y是否成反比？
解題 ▶
🔑 核心觀念
影片裡的「1秒」濃縮了拍攝當下的「很多秒」，這個濃縮倍率＝真實拍攝總秒數 ÷ 影片總秒數。第(2)小題則是把同樣的關係式，改成用 x、y 表示，看乘積 xy 是不是固定值。
💭 思考邏輯
第(1)小題直接算出總時間的比值；第(2)小題延續第(1)題「總拍攝秒數＝x×y×影片秒數」這個關係式，只要 xy 等於一個定值，就代表 x、y 成反比。
📑 解題步驟
①(1) 20小時 = 20×3600 = 72000秒；影片15分鐘 = 900秒
②(1) 濃縮倍率 = 72000÷900 = 80 → 影片中1秒＝拍攝當時80秒
③(2) 拍攝總張數 = 72000/x；影片秒數 = 張數÷y = 72000/(xy)
④(2) 影片秒數固定為900：72000/(xy)=900 → xy=72000÷900=80
⑤(2) xy=80為定值 → x與y成反比
答案：(1) 80秒　(2) 成反比（xy=80為定值）
